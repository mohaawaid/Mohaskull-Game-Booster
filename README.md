برنامج يجهّز جهازك للعب تلقائياً، ويسجّل جلسات اللعب ويوضح لك سبب التقطيع أو نزول الفريمات.

## المميزات

- يكتشف اللعبة لحظة تشغيلها ويجهّز الجهاز (خطة الطاقة، Game Mode، قفل برامج الخلفية)، وبعد ما تقفل اللعبة يرجع كل شيء طبيعي
- يسجّل كل جلسة لعب ويعطيك تشخيص واضح: حرارة، معالج، كرت، إنترنت، أو برنامج شغال بالخلفية
- أوفرلاي بسبعة أشكال، منها شكل مخصص تتحكم فيه بكل عنصر: مكانه وعنوانه وحجمه ولونه. يظهر فوق اللعبة، أو داخلها عن طريق RivaTuner
- كل خيار يغيّر جهازك يبدأ مطفأ، وأنت تفعّل اللي تحتاجه
- حد فريمات ذكي لكل لعبة، يتعدّل بعد كل جلسة حسب جهازك
- مقارنة جلساتك لكل لعبة، وصورة لنتيجة الجلسة تشاركها مع أصحابك
- ما يستخدم أي Driver، فهو آمن مع Vanguard وغيره
- عربي وإنجليزي

## التثبيت

حمّل **Setup** من [آخر إصدار](../../releases/latest) وثبّته، أو **Portable** إذا تبي تشغّله بدون تثبيت.

إذا طلعت لك رسالة Windows protected your PC اضغط More info ثم Run anyway.

## ملاحظات

- قراءة حرارة المعالج والتبريد الذكي تشتغل على لابتوبات MSI فقط
- قراءة الكرت كاملة مع NVIDIA، ومع AMD و Intel تظهر نسبة الاستخدام والذاكرة
- البرنامج ما يرسل أي بيانات، كل شيء يبقى على جهازك
- لو واجهتك مشكلة: من البرنامج «حول» ← «إرسال تقرير مشكلة»، وارفق الملف في [Issues](../../issues/new/choose)
